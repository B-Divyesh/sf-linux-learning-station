Privacy

Short version: a child can use every core activity without an account. We do not collect names, drawings, answers, progress, identifiers, analytics, or advertising data.

Data on this device

The chosen age band and activity results are stored in this browser using IndexedDB. An adult can export a JSON copy, import one, or erase everything from Adult tools. Removing this site’s browser data also removes local progress.

Purchases

When hosted sales are available, checkout is hosted by Sociobot with Dodo as merchant of record. New sales are currently paused. The station stores a restored license token and its latest validity result in this browser. License verification sends that token to the Sociobot API at most once per day. No child activity data is included.

Offline and third parties

The installed station caches its own files for offline use. It loads no third-party fonts, scripts, ads, chat, or trackers. License verification is the only optional third-party request.

Your choices

Use Export data before moving devices. Use Erase progress to delete local learning data. For privacy questions, email privacy@sociobot.in.
